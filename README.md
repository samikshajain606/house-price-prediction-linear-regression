# House Price Prediction using Linear Regression

This project focuses on predicting house prices using a Linear Regression model. The goal is to analyze housing features and build a predictive model that estimates house prices based on relevant numerical and categorical attributes.

## Dataset
- Housing.csv

The dataset contains information such as area, number of bedrooms, bathrooms, parking availability, furnishing status, and other factors that influence house prices.

## Objectives
- Explore and understand the housing dataset
- Clean and preprocess the data
- Convert categorical variables into numerical format
- Build a Linear Regression model
- Evaluate model performance using appropriate metrics
- Visualize actual vs predicted house prices

## Steps Performed
- Data loading and initial exploration
- Handling missing values
- Encoding categorical features
- Feature selection and train-test split
- Model training using Linear Regression
- Model evaluation using Mean Squared Error (MSE) and R-squared (R²)
- Visualization of predicted and actual values

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Results
The Linear Regression model was able to capture the relationship between housing features and price effectively. The evaluation metrics indicate reasonable predictive performance.

## Conclusion
This project provides hands-on experience in building and evaluating a regression-based machine learning model. It demonstrates the practical application of Linear Regression for real-world price prediction problems.
